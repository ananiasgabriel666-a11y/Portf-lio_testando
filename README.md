## ✨ Sobre o projeto

Este portfólio nasceu da ideia de que o lado "técnico" e o lado "criativo" não precisam ser separados. O site reúne apresentação pessoal, formação, habilidades técnicas e comportamentais, com um visual escuro e destaques em vermelho, e transições feitas com JavaScript.

## 🚀 Como executar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/SEU-USUARIO/NOME-DO-REPOSITORIO.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd NOME-DO-REPOSITORIO
   ```
3. Abra o arquivo `index.html` no navegador (ou use a extensão **Live Server** do VS Code).

Não há dependências nem build: basta abrir o HTML.

## 🎨 Personalização

- **Textos e seções:** edite o `index.html`
- **Cores, fontes e espaçamentos:** edite o `style.css`
- **Animações e transições:** edite o `script.js`
- **Fotos:** substitua `eu_na_foto.png` e `foto_retro2.jpeg` mantendo os mesmos nomes (ou atualize os caminhos no HTML)
