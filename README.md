# 💻 Portfólio – Ananias Gabriel

Site de portfólio pessoal desenvolvido para testar habilidades de HTML, CSS e JavaScript.


## ✨ Sobre o projeto

Este portfólio nasceu de uma sequência de tutoriais e vídeos aula que me mostraram que o lado "técnico" e o lado "criativo" não precisam ser separados. O site reúne apresentação pessoal, formação, habilidades técnicas e comportamentais, com um visual escuro e destaques em vermelho.

## 🧭 Seções
Todas as seções são figurativas sendo apenas desenvolvida a "Home", que separa aresentação pessoal e outros aspectos pessoais.

| Seção | Descrição |
|-------|-----------|
| **Home** | Apresentação inicial, foto e botão **Download CV** |
| **Sobre** | Texto pessoal sobre minha trajetória, estudos e projetos |
| **Retomar** | Resumo de áreas de conhecimento (lógica de programação, engenharia de software, banco de dados relacional, redes, trabalho em equipe e conhecimentos básicos) |
| **Experiência** | Experiências profissionais |
| **Educação** | Tecnólogo em Análise e Desenvolvimento de Sistemas – IFSP (2025–2028) |
| **Tech Skills** | Java, Python, HTML5, CSS e outras tecnologias |
| **Soft Skills** | Fácil aprendizado, adaptabilidade, entre outras |
| **Portfólio** | Projetos desenvolvidos |
| **Precificação** | Serviços e valores |
| **Contato** | Formas de contato |

## 🛠️ Tecnologias utilizadas

- **HTML5** – estrutura da página
- **CSS3** – estilização e layout responsivo
- **JavaScript** – efeitos de transição e interações

## 🚀 Como executar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/SEU-USUARIO/NOME-DO-REPOSITORIO.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd NOME-DO-REPOSITORIO
   ```
3. Abra o arquivo `index.html` no navegador (ou use a extensão **Live Server** do VS Code).

Não há dependências nem build: basta abrir o HTML.

## 🎨 Personalização

- **Textos e seções:** edite o `index.html`
- **Cores, fontes e espaçamentos:** edite o `style.css`
- **Animações e transições:** edite o `script.js`
- **Fotos:** substitua `eu_na_foto.png` e `foto_retro2.jpeg` mantendo os mesmos nomes (ou atualize os caminhos no HTML)
